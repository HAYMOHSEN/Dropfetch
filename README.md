Static site for Dropfetch (GitHub Pages).

Publish: push these files to the ROOT of a public repo named `Dropfetch`,
then Settings → Pages → "Deploy from a branch" → main / (root).
After 1–2 minutes:
  https://haymohsen.github.io/Dropfetch/            (landing page)
  https://haymohsen.github.io/Dropfetch/privacy.html (use this as the Store privacy-policy URL)

When the app is live, replace the href="#" of the Store button in index.html with the Store link.
